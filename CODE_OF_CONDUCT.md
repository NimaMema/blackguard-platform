# Code of Conduct

BLACKGUARD aims to be a welcoming, professional community.

- Be respectful and constructive; critique code and ideas, not people.
- No harassment, discrimination, personal attacks or sharing others' private information.
- Keep discussions on-topic and assume good faith.
- Security research must be legal and authorised; do not post exploit details for unpatched issues publicly — use the private channel in [SECURITY.md](SECURITY.md).

Maintainers may remove content and restrict participation that violates these expectations. Report concerns privately to the maintainer via GitHub (@NimaMema).
