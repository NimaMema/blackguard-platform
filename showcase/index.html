BLACKGUARD

The Guardian of Your Network and Information

A security monitoring and defensive-response platform you run yourself. Enrolled agents collect Windows, Linux and router events; transparent rules turn them into evidence-backed incidents; and nothing changes on your network without an administrator's approval.

01 What it does today

Observe

Agents you explicitly enroll and approve collect security events and buffer them durably while offline.

  • Windows Security & System logs (PowerShell agent)
  • Linux auth logs & systemd journal
  • Router/firewall syslog: netfilter, UFW, pfSense/OPNsense, OpenWrt, MikroTik, DHCP
  • Device inventory with per-attribute provenance — never a network scan

Detect

19 deterministic rules mapped to MITRE ATT&CK, with tunable thresholds and written reasoning for every confidence level.

  • Brute force, password spraying, success-after-failures
  • Backdoor accounts, privileged-group changes, log clearing
  • Port scans, cross-device correlation, new devices
  • Collector outages classified: reboot vs. agent stopped vs. unreachable

Defend

Guardian Response proposes actions with their impact and rollback plan; an administrator must approve; a person performs them; everything is audited.

  • Evidence-linked investigation workspace & timeline
  • Approval-gated response workflow — no automatic blocking
  • Markdown, JSON & pseudonymised reports
  • Hash-chained, tamper-evident audit log

04 Security by design

Accounts

Individual users, admin / analyst / viewer roles, scrypt hashing, HttpOnly SameSite=Strict sessions, CSRF tokens, lockout and rate limits.

Agents

One-time enrollment codes, administrator approval with a fingerprint check, hashed per-agent credentials, two-phase rotation, instant revocation.

Data

Secrets redacted before storage, raw logs off by default, pseudonymised exports, verified backups, retention that never deletes open-incident evidence.

Web

Strict Content-Security-Policy, no innerHTML, parameterised SQL, bounded requests, TLS for anything beyond localhost.

Reliability

At-least-once delivery with idempotent storage — tested across server restarts and dropped acknowledgements. Loss cases are documented, never hidden.

No dependencies

The server and Python agent use only the Python standard library. No cloud services, no paid APIs, optional local AI via Ollama.

06 Honest maturity

What it is

  • An experimental, actively developed open-source project
  • Used on a real Windows home setup by its author
  • A foundation designed to grow toward multi-site and business use

What it is not (yet)

  • Not independently security-reviewed or certified
  • Not a replacement for antivirus/EDR or a commercial SIEM
  • No multi-day soak or high-volume benchmark published yet
  • Detections are leads for a human — not proof of compromise
